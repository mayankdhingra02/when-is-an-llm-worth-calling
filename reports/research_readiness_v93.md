# Research readiness after V93

The work now supports a **bounded negative result worth technical review**, not a demonstrated benefit-aware escalation method or an established Q2-level contribution. Journal tier is not an experimental acceptance criterion; these checks concern whether the proposed claims are supported.

| Proposed claim | Evidence now available | Assessment |
|---|---|---|
| A larger local model improves escalation over strong cheap optimization | V91: 30 paired cases on six exposed families; Qwen3 mean gains −1.259% versus same-pool batch 3NN and −3.203% versus full sequential 3NN | Not supported in this adaptation |
| Valid output means useful evidence-based selection | V92: 108 complete conditions; both representations fail the predeclared combined loss/order screen | Output validity alone is insufficient here |
| The forced one-token grammar alone accounts for the observed Qwen3 selections | V93: all 53 returned native answers match forced selection sets; all nine forced repeats match; one resource failure remains unknown | No observed native-decoder rescue on these cases; do not generalize beyond this setup |
| We have a reproducible measured result | Raw local responses, exact prompts and versions, charged requests, tests, independent arithmetic checks, figures and portable saved-response replay | Supported as saved-evidence reproducibility; not an independent experimental replication |
| A benefit-aware router generalizes to unseen software systems | No new untouched evaluation families in V91–V93; older exposed cases cannot be made held out again | Still unsupported |
| The native-workload negative result is portable across machines | Earlier V86 native cheap-control evidence exists, but this turn adds no physical workload measurements or second machine | Still untested |

A defensible current statement is: **In this recorded-table adaptation, valid Qwen3 outputs and a larger model did not establish benefit over cheap controls; development-only interventions exposed sensitivity to arbitrary presentation, and freeing the decoder produced identical observed selections.** This keeps optimization evidence (V91), mechanism evidence (V92–V93), and native-workload evidence (V86) separate.

Do not claim universal LLM failure, semantic non-understanding, model-size causation, a formal reliability guarantee, independent sample size equal to request count, or that a professor/journal will accept the work. The loss-ablation effect is itself representation-dependent. Qwen3 did respond in some cases; that response did not satisfy the frozen screen and does not by itself measure useful optimization.

The V93 memory failure and context-only continuation remain a limitation. The unreturned response is unknown and charged, not silently excluded. The two-context result is not a clean single-runtime replication. The uncertainty bound still rules out passing the chosen stability threshold in this sample; it is not a confidence interval for unseen systems.

## Highest-value next experiment

**Freeze and execute an evaluation on genuinely untouched software families before inspecting their optimization outcomes.** Select families by provenance, correctness, meaningful configuration options and budget eligibility, not by LLM gains. Keep all related variants/seeds together. Fix the current model, prompts, parsing and cheap comparators; carry all failures into the denominator. Decide beforehand whether the confirmatory target is the original router benefit hypothesis or replication of the narrower negative result. Do not mix those targets after results.

The current corpus does not automatically provide such a split. Prior admission audits rejected or already exposed several candidate systems; consult their exposure registry before admitting another. Native clean-machine replication is a separate valuable validity check, not a substitute for additional independent software groups. A new bounded collection plan is required; more retries, new seeds on the same families, favorable prompt selection, or raising memory limits do not close the scientific gap.

Neither a positive finding nor a journal-readiness guarantee is promised. The original broad research goal remains open, while the two new bounded experiments are finished and auditable.
