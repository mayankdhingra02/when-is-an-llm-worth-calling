Exploratory development experiment after V22–V27 exposure. Question: does combining the three existing presentation variants into one selected batch improve quality enough to motivate the extra inference? No new model calls are allowed; use only the provenance-checked real V22 responses. This is a cache-based counterfactual continuation, not fresh inference, a learned router, or an independent held-out study.

Each response proposes ten distinct rows from the same twenty-row prefix-derived shortlist. Map displayed IDs back to actual candidate rows before voting. Count one vote per candidate per response. Select the ten highest counts, breaking ties by the original feature/acquired-label-only static shortlist rank. Freeze this one rule without trying alternative weights, tie-breaks or presentation subsets. Do not use any branch outcomes to choose rows. This is a hybrid of model votes and a classical ranking; any benefit cannot be attributed to model consensus alone.
