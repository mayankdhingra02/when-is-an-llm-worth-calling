# V44 analysis implementation freeze (before any V44 model response)

This addendum implements the unchanged V44 comparisons. Original protocol,
collector, sixty prompts and requested authorization remain unchanged. This
analysis seal is additional, and must precede model collection. These cases
are still exposed exploratory systems, not a new held-out study.

All sixty intended cases are required for primary aggregation. An incomplete
collection retains its intended denominator, cost and failure report, with no
complete-case quality average. Request IDs must be unique, starts and responses
must agree, selected IDs must replay raw output or the prescribed fallback,
and acquired states must replay their journal and shared prefix. Acquired values
must match V43's already acquired pool records. No source-table hidden targets
are needed by this analyzer. Token/grammar replay checks raw-output provenance;
it is not recomputed model inference.

For each pool report four fixed comparisons: own-pool batch3NN, original
batch3NN, full-domain sequential3NN, and outcome-informed pool ceiling. Also
report the exact expected relative gain against a uniform ten-element subset,
using the V42 conditional distribution calculation (expectation of individual
ratios). Report all six family means and equal-family overall means, without
significance tests or picking a favorable comparison.

For a fixed reference, let g be actual relative gain and h be relative gain
if the pool's ceiling were attained. For h>0, signed capture g/h may be negative
and is never clipped to disguise harm. Also retain max(0,g)/h, an explicitly
outcome-informed positive capture diagnostic. For h<=0 both capture values are
undefined (null). Aggregate signed capture only over cases with h>0 and report
its denominator. The ratio sum(max(0,g))/sum(max(0,h)) measures how much total
hindsight opportunity is captured and remains a nondeployable diagnostic.
The ceiling comparison itself has no positive headroom and null capture.

Actual collection reports all requests, starts, errors, tokens when observed,
missing usage as unknown, recorded outcome accesses, stage runtime including
startup, and0external dollars. Historical V43 collection cost is1,200accesses;
V41 collection is3,000accesses. A modeled always-call deployment uses20logical
evaluations and1request per case; its latency includes inherited prefix time,
observed request time and stated loading amortization assumptions. It is not
the cost of collecting both continuations or a claimed wall-clock deployment
measurement. No estimated cloud dollar amounts.

Synthetic fixtures live only in tests/synthetic and temporary test directories.
No V44 measured result will be created until real model records exist. The
postprocessor has a30second stage bound within the unchanged global runtime.
No model calls, new acquisitions, downloads or approvals are enabled by this
addendum. Rendering may be implemented after results without changing endpoints.
