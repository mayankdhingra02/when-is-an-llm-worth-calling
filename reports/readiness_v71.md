# Evidence required for the research objective after V71

The goal remains a credible cost/reliability-aware LLM-escalation result suitable
for journal review. Journal quartile or acceptance cannot be guaranteed. The
current evidence does not yet support a positive generalizable routing claim.

| Requirement | Current evidence | Remaining work |
|---|---|---|
| Reproducible actual experiments | Native logs, frozen protocols, 505 tests; V71 replays 203 trials and 155 decisions | Clean-machine reconstruction of the latest artifacts |
| Shared prefix and fair total budget | V71: 10 shared + 7 search + 3 charged confirmation; 200 actual versus 300 logical charges | Apply exactly this allocation to real LLM and matched controls |
| Useful real LLM continuation | Earlier real calls exist; V65 had 0/5 contract-valid outputs | Test the constrained interface on all preselected development cases; never substitute fixtures |
| Added cost and reliability | Actual attempts, failures, measured runtime, per-read and setting checks | Count local inference retries/tokens/runtime; compare under matched resident-model conditions |
| Strong competing explanation | RF, 3NN and random executed; effects vary by seed | Domain-prior and presentation/legality controls for any LLM advantage |
| Benefit-aware versus uncertainty-only routing | Historical infrastructure exists, but V71 adds one development family only | Paired gains across independent admitted systems; fit rules only on development groups |
| Held-out generalization | Not supplied by V71; 129 measured vectors and five seeds are one family | Unexposed system-level split and precision plan; preserve variants/seeds within family |
| Novelty and claim scope | Prior source audits and limitations exist | Refresh closest-work comparison after a concrete supported contribution emerges |

Do not mark the overall goal achieved on test count, artifact volume, a classical
gain, or a successful model call alone. Do not run indefinitely looking for a
positive p-value. A defensible negative contribution is possible, but needs its own
well-supported scope and comparison; it is not automatically established by failure.
