# V130: prospective native FLAC family pilot

Frozen before the first encoder measurement. This is one new implementation family, not a new held-out cohort or a learned-router evaluation. All three audio workloads and five seeds stay in group `flac`. Historical model/prompt development on other families is disclosed; no prompt or method choice will be changed after these outcomes. A favorable result is not required for task admission. The name LibriSpeech `test-clean` belongs to its original speech-recognition split, not this study's split.

## Admission and equal utility

FLAC 1.5.0 official release, SHA256 `f2c1c76592a82ffff8413ba3c4a1299b6c7ab06c734dee03fd88630485c2b920`, verified against Xiph's published checksum. The CLI is GPL-2.0-or-later; libFLAC uses the Xiph BSD-style license. Build from inspected CMake files, with static libFLAC, Ogg/docs/tests/examples/C++/multithreading disabled. Binary, compiler/SDK choice, linked-library identity and commands are recorded. This is a native configuration adaptation, not a SNAP2 replication. No FLAC execution occurs in prior study evidence found by the admission audit; prior compression families remain separate implementations, but application-domain similarity limits independence claims.

OpenSLR12 LibriSpeech test-clean official archive, published MD5 `32fa31d27d2e1cad72775fee3f4849a9`, plus locally recorded SHA256. License CC BY 4.0; credit Vassil Panayotov (2014). Select numerically first three speakers, then lexicographically first utterance each, before encoding any outcome. Decode entire clips to mono signed little-endian 16-bit PCM at 16 kHz. Freeze sample hashes. No trimming, resampling, fabricated signals or outcome-dependent workload selection. The total 26.655 seconds is a small real speech workload, not music or broad codec evaluation.

Minimize **sum of encoded file bytes over the three fixed clips**, one objective vector per configuration trial. Disable padding and seek tables identically; retain stream checksum and internal `-V` verification. Separately decode every candidate output and compare complete raw sample SHA256 and length to source PCM. A failure is charged and stops native collection, never counted as a good compression outcome. Native wall times include process overhead; record encoder/decoder time separately, but do not optimize latency or infer timing/energy savings. Decoder is the same implementation, not an independent decoder; source integrity plus exact sample identity supports losslessness on these clips.

## Frozen finite domain and strong control

96 argument vectors: block sizes [1024,1536,2048,3072,4096,4608], maximum LPC orders [4,8,10,12], maximum Rice partition orders [0,2,4,6] with minimum 0. All start from `-8`, overriding these three knobs only; preset apodization remains unchanged. Each block is divisible by its maximum partition count, with subblock length greater than LPC order. All meet documented subset limits, avoiding predictable invalid or silently capped partition combinations. Effective behavior/output ties may still occur: 96 argument vectors do not imply 96 distinct encoded results. We deliberately do not add redundant axes merely to reach an earlier 400-row screening preference; 96 valid choices support B20. Report this scope difference explicitly.

The default strongest preset `-8` is (4096,12,6), included as the first observation of every prefix. Initialization: preset plus two shuffled candidates using Python Random(seed); seven acquired-label-only sequential Hamming 3NN choices complete B10. Prediction is exact rational mean of three nearest acquired targets; acquired-order nearest ties and shuffled-candidate-order score ties are stable. Full feature domain can be used, but no unacquired labels exist.

Five fixed seeds 11,23,37,53,71. Save each B10 prefix. Continue independently to B20 with (1) sequential 3NN, (2) fixed batch 3NN, (3) random feature proposals with identical Hamming projection, (4) random full-domain sampling, (5) real local model proposals. Each retains best incumbent. Model uses the fixed V128 capacity-checked ten-string adapter and pinned Qwen3-8B Q4_K_M; five requests, temperature .7/top_p .95/output1024/context4096, seed130000+optimizer seed. Invalid/unattempted response falls back to sequential 3NN and stays in the intended denominator. Projection removes acquired/duplicate selections using frozen order. No label rotation probes or prompt tuning. No retries. No full-domain headroom measurement in this stage.

Classical collection: 50 shared-prefix trials plus 200 continuation trials =250. Model continuation:50 more. Three separately charged preset repeat trials follow selection, testing deterministic byte counts, never feeding an optimizer. Total303 configuration attempts, up to909 encoder and909 decoder invocations. Every physical execution is charged even if another arm selected identical settings; no cache makes deployment cost disappear. Each logical arm remains B20; separately labeled validation probes are outside those arms and not used for decision-making. Corpus decoding/build work is preparation, recorded separately.

Primary comparison: relative byte improvement of LLM arm vs sequential 3NN `(classical - model)/classical`. Report all five paired cases, mean, wins/ties/losses; secondary comparisons against other frozen controls and starting preset. Group-level sample size is one. No inferential group CI, significance, model selection, router fit, non-inferiority or journal-quartile claim. Any hindsight routing envelope is explicitly post-hoc and non-deployable. Do not pool incompatible prior runs to inflate independent N.

Actual collection cost includes every trial, paired arm, model request, token where observed, decoding, build and startup. Estimated deployment is10 prefix+10 selected continuation trials plus one request if escalating; preset-only requires one trial. Byte savings are not dollars. Reproducible tables/figures and independent saved-record verification must precede interpretation. Preserve original failures and prior evidence seal. Nothing is published or sent.
