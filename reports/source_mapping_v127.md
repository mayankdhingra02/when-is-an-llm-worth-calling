# V127 relation to original methods

The original saved primary SNAP2 paper was read again for the specific projection claim, and its bytes were checked against the original source manifest (`artifacts/study_v127/reference_recheck.json`). It describes projecting proposed configurations to the nearest measured row by feature distance and using gpt-oss-120b through OpenRouter. The bounded earlier exact-artifact search did not locate validated executable SNAP2 code; it does not prove none exists. See the original [source audit](source_audit.md) and [paper](https://arxiv.org/html/2607.02583v1).

V127 adopts only the high-level proposal-to-recorded-row idea. Its Qwen3-8B local model, symbolic JSON settings, batch of ten proposals, unweighted Hamming projection, deterministic novelty/tie rule, one-target raw-performance examples, fixed output limit and fallback are our independently implemented choices. They are not an exact reproduction of the paper's prompts, distance, multi-objective score, sequential acquisition or provider setup. No paper author code was imported.

The model sees feature domains and ten acquired examples; it does not see the full candidate table or source outcomes. Projection sees all admitted feature rows and excludes acquired/already-projected rows; it never sees their targets. Random proposals are uniform per feature domain and use precisely the same projection. Thus the control matches the proposal representation and projection, rather than confusing independent feature draws with uniform sampling of valid recorded rows. The full-domain batch and sequential3NN comparisons retain stronger cheap alternatives.

LLAMBO already separates candidate generation and surrogate selection; see the [earlier primary-source check](literature_update_v43.md). V127 does not implement its desired-target conditioning, candidate filtering, retry procedure or complete optimization loop, and no novelty is claimed merely for proposing configurations. The pinned V124 owner code was a numeric surrogate component, not executable provenance for this new proposal adapter. Existing paper/repository/model licensing and the V41 recorded-data correctness/noise/redistribution qualifications remain.
