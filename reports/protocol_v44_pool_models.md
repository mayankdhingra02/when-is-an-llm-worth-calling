# V44 proposed real-model candidate-pool assay

Prepared after V43 outcomes. This is an explicitly exploratory mechanistic assay
on exposed systems, not held-out routing evidence or a confirmatory test. No
threshold, prompt, model, pool or case may be changed after new responses.

Run the already installed, owner-hash-verified Qwen2.5-1.5B-Instruct on BOTH V43
pools, all six software families and all five seeds:60intended calls. Keep the
V41 prefix, V8 prompt/normalization, canonical20candidate-ID grammar, greedyCPU
float32/4threads,20output tokens,4096input-token ceiling,30second per-request
timeout. Shuffle pool presentation with Random(seed+70000) identically to V41.
New prompts and mappings are frozen before inference. Old model outputs cannot
stand in for new prompts. There are no new model downloads or paid endpoints.

Each selected arm retains the original10labels and acquires10outcomes from its
own pool, exactly20logical evaluations. Count every selected-source access even
when V43 already measured it. Invalid/error response falls back to that pool's
saved batch3NN choice and remains in the denominator. Zero request retries;
if a worker dies, stop and checkpoint rather than silently retry or replace cases.
Preserve requests, starts, raw outputs, token IDs, prompt/model hashes, unknown
usage, fallbacks, timestamps and terminated-worker evidence.

Required NEW explicit authorization:60additional calls, follow-up cap290->350,
450seconds maximum collection within unchanged3600seconds globalruntime,
600new recorded accesses maximum, USD0, zero downloads, no request retries.
Prepare/tokenize without generation first. Disabled authorization must reject
before any model loads or requests. The earlier V41 approval has been consumed.

Analysis fixed before responses: for each pool separately compare model final
target to its own batch3NN (primary matched-information comparator), original
batch3NN, full-domain sequential3NN and its measured outcome-informed ceiling.
Report every case and equal-family means, wins/ties/harms, all six family means,
ceiling attainment, fraction of positive ceiling headroom captured, model cost
and failure denominators. Where ceiling offers no positive gain, label capture
undefined rather than dividing byzero. Do not select a favorable pool/comparator.
Exact uniform10of20 reference reuses V43 covered outcomes, conditional on that
pool. Hindsight selection/routing remains a nondeployable diagnostic. No new
significance claims or refitting routers on exposed outcomes. Classical/model
timing is not contemporaneously randomized; do not infer causal speedup.

Decision: if larger candidate-region opportunity is not captured robustly by
the model beyond cheap selection, stop this specific adaptation. A positive
mechanistic result only motivates a new independent development/test design;
it does not establish a useful controller, equal application utility or Q2 readiness.
