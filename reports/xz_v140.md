# V140: native XZ external case study

Executed XZ5.8.4 with 216 frozen configurations and five fixed seeds. Six B20 arms per shared B10 prefix; three unchanged full-resolution RGB PPM photographs. Objective: total lossless compressed bytes. Every output was decoded and checked against the exact source-file SHA256/length. Same-library decoding and reused image workloads limit generalization. All seeds/workloads constitute one XZ software group.

Positive values favor the real local Qwen3-8B continuation.

Benefit and uncertainty parameters remain V132 (40 pairs/eight development groups); no XZ outcome fitted or tuned them. Decisions were saved before each post-prefix branch and all model requests. Random uses the original development rate and fixed seed140900. Realized-rate matching and hindsight are explicitly retrospective diagnostics; hindsight is nondeployable. A zero-call policy matching never is not evidence of useful selective prediction. No statistical independence is claimed for five seeds from one system.

Actual collection: 353 native configuration attempts, 1059 encodes and 1059 decodes; native phase wall time 122.694s. Fifty shared physical prefix trials, 300 continuations, three separately charged reference checks. Reference repeats: [1328952, 1328952, 1328952]; never used in optimization.

Inference: 5 real local requests, 0 retries, 5/5 valid, 0 fallbacks. Observed generated/prefill tokens 361/2990; missing intended usage 0/0. Allocated 5120 output tokens. Model lifecycle 28.525s; peak sampled RSS 6,246,891,520bytes; server exit 0.

Frozen decision computation: 0.002293s total. Historical training time remains unknown. Estimated deployment uses one selected B20 branch and a model call only if selected, plus decision overhead and separately amortized loading. Actual research collection includes every alternative, failed attempt and validation repeat; it is not free policy deployment. Compression-time logs are overhead, not this byte-size objective; no dollar/energy savings inferred.

Limitations: a single new software family cannot validate population transfer or journal readiness; workloads were previously exposed in other codec studies; deterministic file-size behavior does not represent noisy latency objectives. LZMA2 dictionary, threads, checksum and legal option combinations are fixed; this does not compare every standard preset. Same-library decoder, public pretraining familiarity and one host/model constrain scope. All original outcomes and failures remain preserved; no favorable-only subgroup or follow-up tuning. This is a native adaptation, not an exact original-paper experiment.
